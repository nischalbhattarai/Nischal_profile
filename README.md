# Nischal Bhattarai — Portfolio

Personal portfolio website for Nischal Bhattarai, Mechanical Design Engineer based in Melbourne.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to [Vercel](https://vercel.com), [Netlify](https://netlify.com), or GitHub Pages.

## Customize

- **Content:** Edit `src/data/profile.ts` (experience, skills, contact, LinkedIn URL).
- **Resume:** Replace `Resume/Resume.pdf` — it is copied to the site automatically when you run `npm run dev` or `npm run build`.
- **Styling:** Colors and layout live in `src/index.css` and `src/App.css`.
